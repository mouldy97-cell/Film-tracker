    Your ledger

    Progress, backup and where the list came from.

    Poster art is pulled live from The Movie Database as you scroll, and cached on the phone so it only loads once per film. A key is free — themoviedb.org → Settings → API → Create → API Key (v3 auth), then paste it above. Without a key, cards just show a plain initial in place of the art. The key stays on this device and is never included in a backup.

    Sources. The main list is the 1,000 Greatest Films poll compiled by They Shoot Pictures, Don't They (the spreadsheet you supplied, 2025 edition), which aggregates critics' and directors' ballots. Merged into it is a snapshot of the IMDb Top 250, the audience-voted list, which adds 95 films the critics' poll leaves out. Where a film appears on both, the card shows both positions. Directors and years for the IMDb-only entries were filled in by hand, so treat those as the likeliest weak spot. Poster art and film data, where shown, come from TMDb; this product uses the TMDb API but is not endorsed or certified by TMDb.
